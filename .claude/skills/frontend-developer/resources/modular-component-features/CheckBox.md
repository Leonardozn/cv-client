# CheckBox

## Description

An interactive custom-designed boolean input to match the framework's theme.

## Features

- **label (string)**: Descriptive label text next to the checkbox.
- **type (string)**: Determines the color theme when selected (e.g., `"primary"`, `"success"`, custom hex).
- **elevation (number)**: Shadow applied to the checkbox tick area. Default: `0`.
- Standard input checkbox properties like `defaultChecked`.
