# ProgressBar

## Description

A visual indicator used to represent the completion progress of a task.

## Features

- **now (number)**: The current progress value.
- **min (number)**: The minimum bounds of the progress calculation. Default: `0`.
- **max (number)**: The maximum bounds of the progress calculation. Default: `100`.
- **type (string)**: Sets the color of the filled progress bar (`"primary"`, `"success"`, custom hex).
- **elevation (number)**: Shadow applied to the entire bar wrapper. Default: `0`.
