# Badge

## Description

A versatile pill-like component used to highlight statuses, labels, or compact information.

## Features

- **text (string)**: The label displayed inside the badge.
- **type (string)**: Color variant (`"primary"`, `"secondary"`, `"neutral"`, etc.) or custom hex context.
- **outline (boolean)**: Renders the badge with a transparent background and an outlined border matching the type color.
- **icon (ReactNode)**: Optional icon rendered inside the badge.
- **iconPosition (string)**: Position of the icon, either `"start"` or `"end"`.
- **elevation (number)**: Controls shadow depth. Default: `0`.
