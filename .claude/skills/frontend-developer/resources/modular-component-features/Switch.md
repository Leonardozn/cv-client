# Switch

## Description

A boolean toggle component that behaves like a modern on/off switch.

## Features

- **checked (boolean)**: The boolean state of the switch.
- **onChange (function)**: Callback receiving the new boolean state when toggled.
- **disabled (boolean)**: Greys out the switch and makes it non-interactive.
- **type (string)**: The color theme of the switch track when activated (`"primary"`, `"success"`, custom hex). Default: `"primary"`.
