# Spinner

## Description

An animated loading indicator for asynchronous operations or long wait states. Specially designed to not have drop shadows (`elevation`).

## Features

- **type (string)**: Controls the colored stroke of the spinner's rotating ring (`"primary"`, `"error"`, `"neutral"`, custom hex, etc.). Default: `"primary"`.
