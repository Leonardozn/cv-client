# Breadcrumb

## Description

A navigation component that indicates the current page's location within a navigational hierarchy.

## Features

- **path (array)**: Array of strings or objects representing the navigation steps.
- **elevation (number)**: Dropshadow applied to the root element. Default: `0`.
