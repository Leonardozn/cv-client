# Range

## Description

A slider control that allows the user to select a value from a specific range.

## Features

- **label (string)**: Built-in descriptive label for the range slider.
- **elevation (number)**: Add drop shadow to the underlying slider range. Default: `0`.
- Utilizes an underlying `input type="range"` and passes down properties appropriately.
