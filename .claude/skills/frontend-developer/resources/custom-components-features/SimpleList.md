# SimpleList

## Description

A straightforward iteration of list rendering generating sequential unstyled boxes useful to display directories or settings arrays.

## Features

- **items (array)**: Structured array handling configs per list map containing: `{id, primaryText, secondaryText, icon, avatar, action}`.
- **elevation (number)**: Controls outer shadowing parameters. Default: `0`.
