# Radios

## Description

A component that models a group of radio inputs under a unified design system. Note that per design directions, `Radios` explicitly drops the standard `elevation` propagation property.

## Features

- **options (array)**: Array mapping the display texts.
- **type (string)**: Select color variants (`"primary"`, etc) applied universally to the checked layout instances.
- **defaultValue (string)**: Initializes the radio form structure to an already marked choice.
