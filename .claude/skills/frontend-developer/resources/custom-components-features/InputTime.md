# InputTime

## Description

A visual wrapper over `type="time"` allowing custom styling over the native timepicker inputs. Like all custom date elements, misses an `elevation` parameter globally.

## Features

- **label (string)**: Display text for accessibility and context.
- **value (string)**: Represents the HH:MM constraint context.
- **onChange (function)**: Invoked when time is validated and mapped back.
- **type (string)**: Accent theme mapping variant. Default: `"primary"`.
