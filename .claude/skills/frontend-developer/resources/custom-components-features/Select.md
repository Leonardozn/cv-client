# Select

## Description

A highly curated custom dropdown selector simulating an HTML `<select>` tag. Explicitly misses generic `elevation` attributes.

## Features

- **label (string)**: Visible text placeholder labeling the input.
- **options (array)**: Objects comprising `{id, value}` mapping to the dropdown items.
- **type (string)**: Styling preset applied to active and hovered items within the internal dropdown (`"primary"`, custom hex).
