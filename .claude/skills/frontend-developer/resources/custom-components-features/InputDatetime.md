# InputDatetime

## Description

A styled custom component handling `type="datetime-local"`. Includes layout control and theme properties similarly to InputDate. Does NOT take `elevation`.

## Features

- **label (string)**: Floating/fixed label descriptor.
- **value (string)**: Value input control bind state.
- **onChange (function)**: Method triggered when changed.
- **type (string)**: Semantic color/brand alignment variant. Default: `"primary"`.
- **min/max (string)**: Date and time validation bounds.
